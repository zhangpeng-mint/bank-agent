# 本地 Web 工作台 MVP

## 启动与功能

`PYTHONPATH=src python3 -m bankdev_agent web --port 8765`，随后打开 `http://127.0.0.1:8765/`。Windows PowerShell 先设置 `$env:PYTHONPATH='src'`，再执行 `py -3.12 -m bankdev_agent web`。

| 页面 | 能力 |
| --- | --- |
| 概览 | 当前配置下的代码索引计数、活动知识文档/块数量、仓库基线和最近任务 |
| 需求分析 | RequirementFrame 表单、基准样例、template/mock/zhipu 模式、分类事实和证据门禁报告 |
| 知识与代码 | 中文知识检索、接口定位、代码符号检索、结果证据预览 |
| 调用链与影响 | 上游/下游/双向 trace、可点击静态关系图、完整节点列表、影响候选、未解析关系 |
| 契约与冲突 | 当前/历史字段、阻断冲突、HTTP 契约精确对齐 |
| 仓库与索引 | 四仓 snapshot 检查、增量更新代码/知识索引、结构化运行结果 |

需求分析可导出 JSON 与 Markdown，其余成功任务可导出 JSON。导出使用原始后端报告，不把界面用的临时证据引用混入可核验报告。

## 实现边界

后端为 `web.py`，基于 Python 标准库 HTTP 服务；前端为 `web_static/` 中的原生 HTML/CSS/JavaScript，不使用 CDN、第三方字体或远程图形库。CLI 增加 `web` 子命令，直接调用既有服务，不通过 shell 拼接 CLI 命令。

任务由单个 worker 串行执行，索引更新不会与其他 Web 任务并发。界面轮询任务状态，长分析不会阻塞导航。同一服务最多保留 20 个任务结果；清理旧任务时同步清理其证据引用。历史仅在进程内存，重启清空。页面输入仅保留在当前浏览器页面内存，不写 localStorage；刷新会清空未保存输入。

调用图最多可视化前 60 个节点，完整结果保留在节点列表和 JSON。此显示上限与后端图预算分别提示，不把部分图展示成完整关系。图仍是静态索引，不是运行时 trace。

## 本机访问与证据

- 固定绑定 `127.0.0.1`，不提供 `0.0.0.0` 或局域网地址选项。当前服务不是多人部署产品。
- 核验 Host、Origin、Sec-Fetch-Site；API 使用进程级随机会话 token，bootstrap 需要自定义请求头，不开启 CORS。
- 只映射明确的静态资产和 API 路由，不提供目录浏览或任意文件下载。
- API 只接受登记的分析操作，参数限制类型、长度和图预算。JSON 请求体上限 48KB。
- 浏览器不提交任意文件路径读取源码。证据预览使用服务端从结果签发的临时 ID，并再次执行仓库 allowlist 路径检查。
- 代码预览读取配置中的固定 Git commit；知识预览绑定任务产生时的活动 revision/hash，文件或索引变化后拒绝旧引用。每次最多预览 200 行。
- 文档和代码以 `textContent` 渲染，不把知识片段或模型输出作为 HTML 执行。响应设置 CSP、no-store、nosniff 和禁止被 iframe 嵌入。
- 不把模型 key 放入页面或 API 响应，只返回是否配置。要用智谱需在启动服务前设置 `BANKDEV_MODEL_API_KEY`；默认模板不联网，远程模型上下文仍使用阶段 7 的控制。

这些限制服务于单用户本机应用；不能把它当成已完成身份认证、权限隔离、TLS 和运维治理的公网服务。页面只能分析和重建本机索引，不编辑业务源码、配置或知识库。

## 验证

`tests/unit/test_web.py` 覆盖 API 会话门禁、外部 Origin/Host 拒绝、静态文件范围、任意文件/证据拒绝、请求结构和大小、活动文档计数、密钥不回传、后台任务、并发限制、原始报告导出、证据 snapshot/hash 失效及参数边界。

浏览器验收使用真实 01100121 检索、证据预览、调用图、冲突检测与模板需求分析；没有调用远程模型或业务服务。Windows 使用纯 Python 与浏览器路径，但仍未做 Windows 真机验收。

2026-10-06 验证：全量 77 项 unittest 通过（含 10 项 Web 测试）；真实模板报告生成 40 条通过校验的事实，契约检测 5 条字段事实、0 个阻断冲突。HTTP JSON/Markdown 导出通过，原始报告不含 Web 临时引用。内嵌浏览器下载事件等待超时，文件下载落盘尚未在普通浏览器验收。
